## H90 

Adjust Output Gain: Use H90 Control software to check that all Programs and Presets have their Output Gain set to 0 dB, rather than a boosted level.

Lower Program/Algorithm Levels: Press the Parameters button, ensure the P (Program) button is lit, and adjust the Out Gain (Output Gain) for that specific program.

Set Mix to 100%: A mix level set to 50% can sometimes create a perceived volume increase, as it adds the full wet signal to your dry signal.

1. Adjust Output Gain (Most Common Solution)
If a Program is too loud or too quiet, you can adjust its output gain directly. 
Method: Press the Parameters button, ensure the P (Program) LED is lit, and use the knobs to find the Out Gain parameter.
Tip: You can set individual Preset gains or the overall Program Gain to 0 dB or lower to balance your tone.

2. Check "Program Mix" Settings
A common issue is that a Program Mix of 50% can actually result in a perceived volume boost, while moving it toward 100% (wet) or 0% (dry) may reduce the volume depending on how the effect works.

Ensure your Mix is set appropriately. If using a parallel loop, set the mix to 100% and use "Kill Dry" for best results.

3. Adjust I/O Levels
Operating Levels: Ensure your I/O operating levels (Instrument/Line) are matched to your amp/mixer. Using Instrument Level with a Line Level signal can cause drastic volume drops.
Troubleshooting: Set bypass mode to Relay and use an INIT Program (with two THRU algorithms) to check if there is a volume change when bypassing. If there is, adjust I/O levels until the volume is consistent in both states.

4. Fix Algorithm-Specific Issues
Compressors: The EQ Compressor algorithm in the H90 is powerful and can significantly reduce volume if the threshold is too low or the ratio too high. Use the Trim knob within the algorithm to boost the volume back up.
Modulation/Tremolo: Harmonic tremolos or modulation effects can feel quieter because they fade the signal up and down.

5. Using Expression Pedal for Volume Control
You can map an expression pedal to act as a global volume pedal. 
Go to System Menu > I/O > Expression Pedal to calibrate, then map the pedal to the Output Gain parameter to reduce volume dynamically.

## Summary Checklist

Check Program/Preset Gain: Set to 0 dB.
Check Mix: Ensure it's not set to 50% if that causes a volume drop.
Check Routing: Switch from Series to Parallel (or vice versa) to see if that fixes the drop.
Check Compressor: Lower the compression ratio or increase the Trim gain.
